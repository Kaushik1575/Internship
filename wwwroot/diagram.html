Admin Login → Manage Students

1 Admin enters email + password
2 AccountController checks admins table
3 Cookie created (Role = Admin)
4 Admin Panel: search / add / edit / activate
5 AdminController updates apprentices table

Apprentice Register → Dashboard

1 Student registers with ID + password
2 Password hashed → saved in apprentices
3 Login: email + ID + password verified
4 Cookie created (Role = Apprentice)
5 Dashboard shows own data only
