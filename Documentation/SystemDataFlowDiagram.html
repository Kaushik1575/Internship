Figure 3 — Authentication Data Flow

sequenceDiagram
    autonumber
    actor User as User (Admin / Apprentice)
    participant View as Login View
    participant AC as AccountController
    participant PH as PasswordHelper
    participant DB as MySQL
    participant Cookie as Auth Cookie

    User->>View: Enter credentials
    View->>AC: POST Login form data
    AC->>DB: SELECT user by email
    DB-->>AC: User record + password hash
    AC->>PH: VerifyPassword(input, hash)
    PH-->>AC: true / false

    alt Valid & Active
        AC->>Cookie: SignIn (Id, Name, Email, Role)
        Cookie-->>User: Session cookie stored
        AC-->>View: Redirect to Dashboard
        View-->>User: Admin Panel OR Apprentice Panel
    else Invalid or Inactive
        AC-->>View: Error message
        View-->>User: Show login error
    end
