HOW TO ADD DATA FLOW DIAGRAMS TO YOUR REPORT
=============================================

1. Open this file in Chrome or Edge (double-click):
   SystemDataFlowDiagram.html

2. Wait 2-3 seconds for all 5 colorful diagrams to load.

3. For each diagram (Figure 1 to Figure 5):
   - Right-click the diagram → Save image (if available)
   OR
   - Use Windows Snipping Tool / Win+Shift+S to capture the diagram
   OR
   - Press Ctrl+P → Save as PDF → crop each figure in Word

4. In Microsoft Word:
   - Insert → Pictures → select your screenshot
   - Add caption: "Figure 1: Context Diagram (Level 0)" etc.

5. Recommended figures for internship report:
   - Figure 1: Context Diagram (overview)
   - Figure 2: Level 1 DFD (main technical diagram)
   - Figure 3: Authentication flow
   - Figure 4: Admin student management
   - Figure 5: MVC request pipeline
